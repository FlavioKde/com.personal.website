## Bienvenido a mi portfolio

Este portfolio simula un entorno de desarrollo tipo VSCode. El cual puedas navegar y encontrar información de contacto, mejores proyectos y estadisticas

## Archivos disponibles

- `About.jsx`
- `CV.jsx`
- `Projects.jsx`
- `Contact.jsx`

## Como navegarlo

Haz clic en cada archivo para obtener la información 

- `About.jsx`: Presentación inicial y resumen de perfil.  
- `Projects.jsx`: Selección de proyectos destacados, organizados por tipología.  
- `Contact.jsx`: Formulario para enviarme un correo o información de contacto directo.  
- `CV.jsx`: Curriculum con experiencia profesional y opción de descarga.  

## 🛠️ Tech Stack

**Frontend**
- React + Vite  
- TailwindCSS  

**Backend**
- PHP + PHPMailer  
- Proxy para conexión segura con GitHub API  
- Autenticación con OAuth2  
- Email service en Google Cloud  

## Concepto

La idea es un portfolio técnico que simula un entorno de desarrollo tipo VSCode.  
El backend es minimalista pero incorpora seguridad en el manejo de emails mediante OAuth2 y Google Cloud.  
Existe un proxy entre el frontend y las solicitudes a la API de GitHub para proteger las credenciales y garantizar la seguridad de las requests/responses.  
El correo propio se gestiona con la librería PHPMailer.  

En resumen: un portfolio que combina API, backend y seguridad en un mismo proyecto.
